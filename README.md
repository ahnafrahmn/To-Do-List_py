# To-Do List

A simple project on python. I have used most of the common beginner level functionalities so that it feels easier to adopt if a beginner is trying to learn. I have focused on very basic usage of it. I assumed what would I need in a "To-Do List App" if I were to use it. So I have drawn some diagrams and tried to articulate the layers. And then I started to code. 

I loved creating something I personally would like to use for my daily use. It isn't too fancy but it is easy to use, very minimal options so that even toddlers get it, no extra layer of confirmation. At last I was thinking that should I give it a security for logging in, then I thought that would make it lose its simplicity.
